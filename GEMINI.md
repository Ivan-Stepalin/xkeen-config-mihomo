# Правила работы с репозиторием `xkeen-config-mihomo`

Все изменения в конфиге, правилах и скриптах **сначала обкатывать локально на `dev`**, и только после успешной проверки выкатывать на роутер (`192.168.1.1`):

1. **Проверка конфига и секретов (локально на `dev`):**
   - `ruby scripts/validate.rb` — проверка структуры, ссылок на группы и пересечений правил.
   - `ruby scripts/scrub.rb < config.yaml > /dev/null` — проверка, что все секреты закрыты плейсхолдерами и не утекут в git.
   - `mihomo -t -d /tmp/mihomo-test -f config.yaml` — проверка схемы движком (если бинарник установлен).
2. **Проверка скриптов, правил и сервисов (локально на `dev`):**
   - Изменения в скриптах или связанном бэкенде (`youvpn-xray` на LXC 105) сначала проверять локально на `dev`.
   - При правках в `rules/*.yaml` помнить, что роутер тянет их с GitHub после `git push` (исключение: `rules/edge-cache.yaml` в `.gitignore`, в git не добавляется и при правках копируется в `/opt/etc/mihomo/rule-providers/` вручную).
3. **Выкатка на роутер — только горячее перечитывание (`./scripts/deploy`):**
   - Запускать только после прохождения локальных проверок.
   - Использовать **только `./scripts/deploy`** (без `--restart` и без `xkeen -restart`), если не менялись слушатели/порты (`redir-port`, `tproxy-port`, `external-controller`): это перечитывает конфиг по API `PUT /configs?force=true`, не пересоздаёт `iptables`, не рвёт домашний интернет и не роняет соединение `agy-bot`.
   - После деплоя проверить `http://192.168.1.1:9090/proxies` и отсутствие ошибок в `/opt/var/log/mihomo/error.log`.
